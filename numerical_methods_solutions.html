Image 1 - Question 1(a)

Evaluate the sum \(S = \sqrt{3} + \sqrt{5} + \sqrt{7}\) to 4 significant digits and find its absolute and relative error.

Exact values:

  • \(\sqrt{3} = 1.732051... \approx 1.732\)
  • \(\sqrt{5} = 2.236068... \approx 2.236\)
  • \(\sqrt{7} = 2.645751... \approx 2.646\)

Approximate sum (4 sig digits) \(S_a = 1.732 + 2.236 + 2.646 = 6.614\)

True sum \(S = 6.613870...\)

Absolute error \(E_a = |S - S_a| = |6.613870 - 6.614| = 0.000130\)

Relative error \(E_r = \frac{E_a}{S} = \frac{0.000130}{6.613870} = 1.964113e-05\)

Absolute Error = 0.000130, Relative Error = 1.964113e-05

Image 1 - Question 6(a)

From the Taylor series for y(x), find y(0.1) correct to four decimal places if y(x) satisfies \(y' = x - y^2\) and \(y(0) = 1\).

Taylor series formula: \(y(h) = y(0) + h y'(0) + \frac{h^2}{2!}y''(0) + \frac{h^3}{3!}y'''(0) + \frac{h^4}{4!}y^{(4)}(0) + \dots\)

Derivatives at \(x = 0, y = 1\):

  • \(y(0) = 1\)
  • \(y' = x - y^2 \implies y'(0) = 0 - (1)^2 = -1\)
  • \(y'' = 1 - 2yy' \implies y''(0) = 1 - 2(1)(-1) = 3\)
  • \(y''' = -2(y'^2 + yy'') \implies y'''(0) = -2((-1)^2 + 1(3)) = -8\)
  • \(y^{(4)} = -2(2y'y'' + y'y'' + yy''') = -2(3y'y'' + yy''') \implies y^{(4)}(0) = -2(3(-1)(3) + 1(-8)) = 34\)

\(y(0.1) = 1 -0.1000 +0.0150 -0.00133 +0.00014 = 0.9138\)

y(0.1) = 0.9138

Image 2 - Question 7(b)

Find the distance covered by the car in 12 seconds given the velocity table.

There are 7 data points, so \(n = 6\) intervals. Since \(n\) is even, we use Simpson's 1/3 Rule.

\(D = \int_0^{12} v dt \approx \frac{h}{3} [v_0 + v_6 + 4(v_1 + v_3 + v_5) + 2(v_2 + v_4)]\)

\(D = \frac{2}{3} [4 + 136 + 4(6 + 34 + 94) + 2(16 + 60)]\)

\(D = \frac{2}{3} [140 + 4(134) + 2(76)] = 552\)

Distance = 552 m

Image 3 - Question 4(a)

Evaluate \(\int_0^1 e^{-x^2} dx\) by using Simpson's 1/3 and Simpson's 3/8 rule taking n=4.

For \(n=4\), \(h = \frac{1-0}{4} = 0.25\). Values of \(x\) are 0, 0.25, 0.5, 0.75, 1.0.

Simpson's 1/3 Rule

\(I_{1/3} = \frac{h}{3}[y_0 + y_4 + 4(y_1+y_3) + 2y_2] = 0.74686\)

Simpson's 3/8 Rule

Simpson's 3/8 rule strictly requires \(n\) to be a multiple of 3. If forced to evaluate using \(n=4\), there isn't a direct standard application over all intervals identically. Usually, we evaluate using \(n=3\) (h=1/3) to demonstrate the rule.

Evaluating with \(n=3, h=1/3\): \(I_{3/8} = \frac{3h}{8}[y_0 + 3y_1 + 3y_2 + y_3] = 0.74699\)

Simpson's 1/3 (n=4): 0.7469
Simpson's 3/8 (n=3): 0.7470

Image 3 - Question 5(b)

Using Taylor series method with the first five terms in the expansion find y(0.1) correct to three decimal place, given that \(\frac{{dy}}{{dx}} = e^x - y^2\), \(y(0)=1\).

Taylor series up to 5 terms: \(y(h) = y(0) + h y'(0) + \frac{h^2}{2}y''(0) + \frac{h^3}{6}y'''(0) + \frac{h^4}{24}y^{(4)}(0)\)

Given \(x_0 = 0, y_0 = 1\):

  • \(y(0) = 1\)
  • \(y' = e^x - y^2 \implies y'(0) = e^0 - 1^2 = 0\)
  • \(y'' = e^x - 2yy' \implies y''(0) = 1 - 2(1)(0) = 1\)
  • \(y''' = e^x - 2(y'^2 + yy'') \implies y'''(0) = 1 - 2(0^2 + (1)(1)) = -1\)
  • \(y^{(4)} = e^x - 2(2y'y'' + y'y'' + yy''') = e^x - 2(3y'y'' + yy''') \implies y^{(4)}(0) = 1 - 2(3(0)(1) + (1)(-1)) = 1 - 2(-1) = 3\)

\(y(0.1) = 1 + 0 + 0.005 - 0.0001667 + 0.0000125 = 1.00485\)

y(0.1) correct to three decimal places: 1.005
